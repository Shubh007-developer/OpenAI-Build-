## 🚀 Quick Start

### Prerequisites
- Git
- Node.js (LTS) and npm, or Python 3.8+
- OpenAI API key

### Installation
```bash
# Clone the repository
git clone https://github.com/Shubh007-developer/OpenAI-Build-.git
cd OpenAI-Build-

# Install dependencies
npm install  # or pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Add your OPENAI_API_KEY to .env

# Start the application
npm start  # or python main.py
```
